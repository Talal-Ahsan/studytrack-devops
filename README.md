# StudyTrack DevOps Assignment

StudyTrack is a database-driven academic management web application created for DevOps Assignment 3.

The project includes a Node.js and Express web application, MySQL database connectivity, and Selenium automated test cases.

## Features

- Dashboard with student, course, and assignment statistics
- Student management
- Course management
- Assignment management
- Search functionality
- Status and priority filters
- Assignment status update
- Delete operations
- Health check route
- Selenium test automation

## Technologies Used

- Node.js
- Express.js
- EJS
- MySQL
- XAMPP MySQL for local database
- HTML
- CSS
- Python
- Selenium
- Pytest
